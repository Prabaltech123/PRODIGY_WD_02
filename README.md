# Stopwatch Web Application

## Prodigy InfoTech Internship – Task 2

### About the Project
This is an interactive Stopwatch Web Application developed as part of my Prodigy InfoTech Web Development Internship.

The application allows users to measure elapsed time with simple stopwatch controls.

### Technologies Used
- HTML5
- CSS3
- JavaScript

### Features
- Start stopwatch
- Pause stopwatch
- Reset stopwatch
- Real-time timer display
- Responsive user interface

### Project Structure
```text
PRODIGY_WD_02/
├── index.html
├── style.css
├── script.js
└── README.md
```

### How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
